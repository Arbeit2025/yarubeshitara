# やるべしたら Web版（yarubeshitara）

Markdown のチェックリスト記法で読み書きできる、手帳風の小さなタスク管理ツールです。

## 使い方

- **タスクの追加**：入力欄から1件ずつ追加できます。チェックボタンで完了／未完了を切り替え、削除もできます。
- **Markdown インポート**：テキストエリアに Markdown を貼り付けて取り込むと、行ごとにタスクになります。
  - `- [ ] タスク` → 未完了タスク
  - `- [x] タスク` → 完了済みタスク
  - `- タスク` のような箇条書きや、ただの文章の行もそのままタスクになります（空行は無視）。
- **Markdown エクスポート**：「Markdownでエクスポート」のリンクから、全タスクを `- [ ] タスク` 形式のテキストファイル（.md）として書き出せます。コピーして手帳アプリやメモに貼る、といった使い方ができます（書き出したものをそのままインポートに戻すこともできます）。

データは SQLite に保存されます。DB のパスは環境変数 `YARUBESHITARA_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 期限・優先度・並べ替えの機能はありません。書いた順の一覧だけです。
- Markdown の解釈はチェックリストと箇条書きだけの単純なものです（見出しや表などは行テキストとして取り込まれます）。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
